# Local Image Tools · 本地图片工具箱

两个独立、无需安装的浏览器图片工具：批量水印与横纵拼接。纯 HTML、CSS、JavaScript，无框架、无运行时依赖、无构建步骤。

维护者：JamesYang。

## 使用

下载本目录后，用近期版本桌面浏览器打开 `watermark.html` 或 `stitch.html`。无需联网。也可在本目录运行 `python3 -m http.server 8080 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8080/`。

- **水印**：批量导入图片，选择文字、图片或双图层；调整位置、透明度、旋转和平铺；导出 PNG/JPEG，可打包 ZIP。支持导入自有字体。
- **拼接**：导入多图，横向或纵向排列，拖动缩略图排序；调整单图缩放和偏移，裁剪整体，导出 PNG/JPEG。
- 原图不会被应用覆盖。若浏览器请求选择输出目录，请选独立空目录，避免与已有文件重名。

## 隐私

图片处理在浏览器内完成，无上传端点或遥测。水印参数（含输入文字）存于 localStorage，导入字体及低于 4 MiB 的水印图片和其文件名存于 IndexedDB；使用共享设备后请清除本站点数据。图片、Logo 和字体的使用权由使用者自行确认。详情见 [PRIVACY.md](PRIVACY.md)。

## 兼容性与限制

优先使用近期桌面 Chrome、Edge 或 Safari；本次验证覆盖范围见发布包外的测试报告，未经测试的平台不保证兼容。浏览器内存和 Canvas 大小限制会影响大图；拼接的面积预检并不保证设备有足够内存。原始 EXIF、色彩配置与元数据是否保留未作保证。目录导出依赖浏览器 File System Access API，直接打开 HTML 时使用下载方式。

## 开发与维护

直接编辑各 HTML 文件即可；两个工具独立运行。本次候选版保留既有工具代码，未引入第三方包。问题反馈时请使用合成图片重现，不提交真实证件、私人图片或商业素材。
